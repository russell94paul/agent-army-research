# Agent Army Master Context

## Product thesis

Agent Army may become:

# An Artificial Organization Engineering Platform

It is an environment where humans can design, instantiate, operate, observe, debug, teach, simulate, govern and evolve artificial organizations.

## Current product lineage

The current system is an Agent Factory:

- build agents,
- build teams,
- run missions,
- manage sessions,
- use tools,
- interact with repos/APIs/databases,
- verify work,
- measure outputs.

Agent Army is the higher-level product thesis:

- design organizations,
- compile missions into teams,
- manage organizational knowledge,
- measure organizational health,
- run simulations,
- evolve better organizations,
- provide a living command-world interface.

## Core analogy

```text
Software IDE
  edits and debugs software

Agent Army IDE
  designs and debugs artificial organizations
```

## Important distinction

Do not build a toy game.

Do not build a military skin.

The Army metaphor should expose real organizational mechanics:

```text
ARMY ORGANIZATIONAL IDEA          AGENT ARMY

Mission intent                 → Intent Contract
Mission command                → bounded autonomy
Staff functions                → specialist cognition services
Running estimates              → continuous world models
Common operational picture     → Organizational Digital Twin
Readiness                      → capability readiness
Logistics                      → context / skill / compute supply
Distributed command            → decentralized agents
Shared understanding           → collective cognition
Training                       → simulation / evaluation
After Action Review            → mission learning
Lessons learned                → validated organizational knowledge
Doctrine                       → executable organizational policy
Task organization              → dynamic team composition
Federation                     → multi-organization interoperability
```

## Core product promise

```text
I can look at my artificial organization
and understand:

what it is doing,
why it is doing it,
what it knows,
what it does not know,
what it can do,
where it is blocked,
what it is learning,
what it costs,
how it is organized,
whether it is still aligned with my intent,
and how it could organize itself better.
```

## Avoid premature implementation

Do not start with:

- autonomous self-evolution,
- complex morphogenesis,
- uncontrolled agent spawning,
- production evolutionary search,
- fake avatars wandering around.

Start with:

- identity,
- events,
- world state,
- evidence,
- provenance,
- replay,
- inspectors,
- stable UI,
- metrics,
- governance.
