# Agent Army Experiment Plan

## Purpose

Prove which ideas actually work.

## Baselines

- single agent,
- fixed orchestrator,
- fixed multi-agent team,
- shared-memory team.

## Variants

- artifact-centered knowledge,
- intent contracts,
- cognitive logistics,
- stigmergic signals,
- field-aware routing,
- adaptive team formation,
- doctrine reuse,
- simulation-evolved topology.

## Metrics

```text
verified success
latency
cost
tokens
messages
tool calls
human intervention
duplicate work
regression rate
intent alignment
knowledge reuse
skill reuse
readiness
```

## Mission corpus

Include:

- connector migration,
- schema issue,
- regression investigation,
- API change,
- data-quality incident,
- unknown repo onboarding,
- code review,
- release validation.

## Key tests

1. Does cognitive logistics reduce context/tokens?
2. Does intent contract reduce unsafe actions?
3. Does artifact-centered knowledge reduce duplicated research?
4. Does field-aware routing improve task assignment?
5. Does a NOW/NEXT/LATER structure reduce idle time?
6. Does doctrine reuse improve repeated missions?
7. Does the UI reduce time-to-understanding?

## Output format

Every experiment should produce:

```text
hypothesis
baseline
variant
dataset
metrics
result
confidence
failure notes
recommendation
```
