# R31 — Frontier Search: New Primitives for Artificial Organizations

## Objective

Search beyond the current concepts.

Find primitives current agent frameworks may not have a name for.

## Search domains

- biology,
- ecology,
- swarm robotics,
- neuroscience,
- economics,
- market design,
- organizational science,
- game theory,
- distributed systems,
- control theory,
- cybernetics,
- operations research,
- artificial life,
- process mining,
- logistics.

## For every concept

Provide:

```text
CONCEPT
SOURCE DOMAIN
ORIGINAL MECHANISM
TRANSLATION TO AGENT ARMY
RUNTIME PRIMITIVE
UI REPRESENTATION
USER VALUE
PERFORMANCE VALUE
COMPLEXITY
RISKS
EVIDENCE LEVEL
RECOMMENDATION
```

## Required output

Find at least 25 concepts.

Rank top 10 by:

```text
value × feasibility × novelty ÷ complexity
```

End with:

> What should be first-class in an artificial organization that current agent frameworks do not even name?
