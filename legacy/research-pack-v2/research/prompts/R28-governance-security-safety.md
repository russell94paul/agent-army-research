# R28 — Governance, Security and Safety for Adaptive Artificial Organizations

## Objective

Design hard boundaries before autonomy.

## Governance layers

```text
CONSTITUTION
hard limits

POLICY
operational rules

STRATEGY
mission approach

PREFERENCE
learned optimization
```

## Risks

Study:

- runaway spawning,
- recursive delegation,
- cost explosion,
- tool misuse,
- secret exposure,
- stale knowledge,
- poisoned knowledge,
- reward hacking,
- false consensus,
- hidden policy changes,
- uncontrolled skill propagation,
- self-modification.

## Operator autonomy levels

```text
MANUAL
SUGGEST
GUARDED AUTO
AUTONOMOUS
```

## Controls

- emergency stop,
- pause mission,
- freeze topology,
- revoke skill,
- quarantine knowledge,
- cap budget,
- force verification,
- rollback organization version.

## Required output

Produce:

- threat model,
- constitution model,
- permission architecture,
- autonomy levels,
- governance UI,
- audit model,
- quarantine/rollback,
- staged autonomy roadmap.

End with:

> Which rules must an artificial organization never be able to rewrite about itself?
