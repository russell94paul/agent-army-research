# R30 — Evaluation, Benchmarks and Experiments

## Objective

Prevent architecture-by-metaphor.

Every Agent Army mechanism needs evidence.

## Baselines

Compare against:

```text
single strong agent
fixed orchestrator
fixed multi-agent team
shared-memory team
```

## Variants

```text
artifact-centric knowledge
stigmergic coordination
adaptive team sizing
morphogenetic team rules
intent contracts
cognitive logistics
learned information routing
evolved organization
```

## Metrics

```text
verified success
latency
dollar cost
tokens
tool calls
messages
context bytes
human intervention
duplicate work
regression rate
recovery time
verification depth
false-confidence rate
knowledge reuse
skill reuse
intent alignment
readiness
```

## Required output

Produce:

- benchmark suite,
- mission corpus,
- experiment matrix,
- ablation plan,
- longitudinal tests,
- UI usability study,
- statistical methodology,
- acceptance thresholds,
- automation plan.

End with:

> Which Agent Army ideas actually outperform simpler fixed-agent systems?
