# Claude Prompt — Design Agent Army Command World UI

You are designing the UI for **Agent Army**, an Artificial Organization Engineering Platform.

The interface should not be a normal dashboard.

It should feel like:

- a premium command center,
- a real-time strategy operations map,
- an IDE for artificial organizations,
- a digital twin,
- a distributed-systems debugger,
- and a high-end observability tool.

## Core concept

Agents inhabit the software environment they modify.

Map:

```text
Mission       → Operation
Agent         → Unit
Team          → Squad / Cell
Repository    → Base / District
Service       → Facility
Database      → Infrastructure
API           → Gateway
Artifact      → Object / Site
Tool          → Equipment
Evidence      → Intelligence
Dependency    → Route
Blocker       → Roadblock
Queue         → Traffic
```

Keep technical labels visible. Do not let the metaphor hide engineering reality.

## Required design

Create a polished UI with:

- HQ overview,
- main Command World,
- operations rail,
- intelligence panel,
- timeline/replay,
- agent inspector,
- squad inspector,
- artifact inspector,
- knowledge inspector,
- lens selector,
- alerts,
- minimap or radar,
- command palette.

## Lenses

Include these as visible toggle chips:

```text
Default
Risk
Knowledge
Intent
Readiness
Logistics
Verification
Contention
Cost
Evolution
```

## Visual style

Original.

Do not copy GTA, Call of Duty, Palantir, Anduril, NATO, Army, or any specific game UI.

Visual tone:

```text
dark
premium
cinematic
technical
high density
clear
alive
mission-control
```

## Motion

Animate only meaningful state:

```text
agent moves = scope change
route pulse = handoff
ripple = signal propagation
formation = squad created
lock = verification passed
scan = investigation
```

## Output

Produce:

1. full UI design concept,
2. component hierarchy,
3. screen layout,
4. design tokens,
5. motion rules,
6. interaction rules,
7. responsive behavior,
8. implementation notes for React/TypeScript.

The result should be something a developer can build, not just a mood board.
