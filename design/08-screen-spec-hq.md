# Screen Spec — HQ

## Purpose

Answer:

> What requires my attention across the whole artificial organization?

## Primary regions

### Command header

- organization name,
- active missions,
- autonomy mode,
- global alerts,
- cost burn,
- human-required count.

### Operational map

Small organization-wide map showing mission clusters and hotspots.

### Readiness board

Capabilities that are:

```text
READY
DEGRADED
BLOCKED
UNKNOWN
```

### Mission portfolio

For each mission:

- intent,
- state,
- verified progress,
- risk,
- cost,
- blocking condition,
- human intervention.

### Organizational health

- verification coverage,
- contention,
- unknown-area coverage,
- event backlog,
- token burn,
- failure recovery,
- knowledge freshness.

## Interaction

Click any abnormal metric → jump to filtered Command World.
