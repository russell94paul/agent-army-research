# Agent Army Design System

## Goal

Create an original visual system for a living artificial-organization command world.

Do not copy military UIs or game assets.

The design should feel:

```text
premium
dark
cinematic
technical
alive
high-density
legible
slightly playful
serious under pressure
```

## Visual directions

### 1. COMMAND

Premium operations center.

Keywords:

```text
strategic
precise
dark glass
signal overlays
radar-like maps
intelligence panels
minimal ornament
```

Best for daily professional use.

### 2. FIELD

Living simulation map.

Keywords:

```text
agents moving
routes
territory
field overlays
logistics lines
squad formations
mission zones
```

Best for understanding operations spatially.

### 3. STREET

Original early-2000s open-world-inspired cyber-city.

Keywords:

```text
districts
facilities
routes
traffic
neon infrastructure
agents moving between buildings
```

Best for alternate playful mode, demos and strong identity.

## Avoid

```text
cheap camouflage
literal toy soldiers
war gore
copied game UI
unreadable labels
random movement
glowing everything
meaningless animations
```

## Color roles

Use semantic colors, not decoration.

```text
Risk
Uncertainty
Knowledge
Verification
Cost
Contention
Readiness
Intent Alignment
Blocked
Human Required
```

Actual color values should be finalized in the product design system.

## Typography

Prefer:

- highly legible sans-serif for UI,
- tabular numbers for metrics,
- restrained uppercase for command labels,
- monospace only for logs/code/data.

## Layout principles

- world center,
- mission context top,
- operations rail left,
- inspector right,
- timeline bottom,
- alert stack anchored,
- minimap optional,
- command palette available.

## Accessibility

Must include:

- reduced motion,
- keyboard navigation,
- screen-reader equivalent tables,
- non-color indicators,
- high contrast,
- table/tree fallback for world view.
