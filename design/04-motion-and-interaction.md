# Motion and Interaction System

## Motion must be semantic

```text
movement    = real operational transition
pulse       = new event
ripple      = signal propagation
route flow  = handoff / dependency / supply
formation   = team created
collapse    = team dissolved
scan        = investigation
lock        = verification complete
break       = verification failed
```

## Interaction model

- click entity → inspect,
- double click → focus camera,
- shift select → multi-select,
- drag box → select agents/teams,
- command palette → issue commands,
- scrub timeline → replay,
- click alert → jump to location,
- toggle lens → transform world state.

## Commands

Examples:

```text
Deploy investigation squad
Request verification
Pause agent
Resume agent
Reassign artifact
Open evidence
Create breakpoint
Compare organization versions
Run after-action review
```

## Reduced motion

All animated state must have non-motion equivalents:

- icon,
- label,
- metric,
- outline,
- table row,
- status chip.
