# Agent Army UI Surfaces

## HQ

Global view:

- active operations,
- deployed agents,
- squads,
- readiness,
- costs,
- verification coverage,
- unresolved risks,
- human-required actions,
- recent wins/failures.

## Command World

Main digital twin.

Shows:

- agents,
- teams,
- artifacts,
- routes,
- fields,
- alerts,
- mission zones,
- logistics/context flows.

## Mission View

Shows:

- intent,
- objective,
- end state,
- constraints,
- phases,
- evidence,
- verification,
- cost,
- timeline.

## Squad View

Shows:

- topology,
- roles,
- workload,
- ownership,
- health,
- capability,
- communication,
- handoffs.

## Agent Inspector

Answers:

```text
Who is this?
What is it doing?
Why is it here?
What does it know?
What tools can it use?
What is it waiting for?
What evidence has it produced?
What has it cost?
```

## Artifact Inspector

Shows:

- active agents,
- recent edits,
- risk,
- uncertainty,
- claims,
- evidence,
- tests,
- dependencies,
- regression history.

## Knowledge Inspector

Shows:

- claim,
- evidence,
- provenance,
- confidence,
- contradictions,
- consumers,
- last verified,
- staleness.

## Capability Map

Shows what the organization can reliably do.

## Timeline / Replay

Scrub mission history.

## Organizational Debugger

Breakpoints, causal stack, decision trace.

## Profiler

Where time, money, tokens and effort went.

## Evolution Chamber

Simulate and compare organization variants.
