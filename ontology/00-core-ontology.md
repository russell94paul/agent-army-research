# Core Ontology — Draft

## Organization

Persistent logical entity representing the artificial organization.

Owns:

- policies,
- capabilities,
- knowledge,
- organization versions,
- missions,
- governance state.

## Mission

A bounded desired outcome with intent, constraints, resources and verification requirements.

## Operation

A runtime execution of a mission.

## Agent

An executing decision-making worker instance.

## Role

A responsibility template. Not equivalent to capability.

## Team

A set of agents collaborating under a mission or sub-mission.

## Cell

A temporary, dynamically created organizational unit.

## Staff Function

A persistent organizational cognition responsibility such as intelligence, operations or logistics.

## Artifact

A work object:

```text
file
repo
table
API
document
ticket
deployment
test
```

## Capability

Evidence-backed statement that an agent/team/organization can reliably perform a class of work.

## Skill

Versioned reusable procedure/tooling package.

## Knowledge Object

Validated organizational information with provenance.

## Claim

A proposition whose truth is not assumed.

## Evidence

An observation or artifact that supports or contradicts a claim.

## Policy

Operational rule.

## Doctrine

Validated persistent organizational procedure or decision principle.

## Intent Contract

Mission objective, end state, invariants, authority and escalation boundaries.

## Event

Immutable record of relevant state transition.

## Signal

Time-varying local organizational indicator deposited on an entity.

## Field

Derived distribution of one or more signals across organizational entities.

## Running Estimate

Continuously updated assessment maintained by a staff function.

## Organization Version

Versioned configuration of topology, policies, skills and other persistent organization-level design choices.
