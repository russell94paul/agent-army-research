## Core product hypothesis

Agent Army is exploring an engineering environment in which the programmable object is an **artificial organization**, not merely an individual agent or workflow.

Candidate stack:

```text
Command World / Organization IDE
Organizational Observability + Debugger
Organizational Compiler
Collective Cognition Fabric
Organizational Runtime / OS
Execution Substrate
Evolution Chamber
```
