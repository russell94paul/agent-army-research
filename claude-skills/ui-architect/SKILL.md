# Skill — Agent Army UI Architect

## Purpose

Design a premium high-density operating surface for artificial organizations.

## Required questions

Every screen must help answer some subset of:

```text
What is happening?
Why?
What changed?
What is blocked?
What is uncertain?
What does the organization know?
Where did that knowledge come from?
Which capabilities are ready?
What needs human attention?
What evidence proves completion?
```

## Visual rules

- stable spatial geography;
- semantic zoom;
- motion maps to state;
- uncertainty is visible;
- technical reality remains inspectable;
- table/tree fallback for precision;
- reduced motion supported;
- no random wandering avatars;
- no camouflage/gimmick-first decoration;
- no force-directed jitter during routine updates.

## Deliverables

For each screen:
- task,
- information hierarchy,
- components,
- interactions,
- state encodings,
- metrics,
- empty/loading/error states,
- accessibility,
- performance considerations,
- operator usability tests.
