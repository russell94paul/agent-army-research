# Skill — Organizational Knowledge Curator

## Purpose

Convert mission experience into trustworthy organizational knowledge without contaminating memory.

## Never collapse

```text
observation
claim
evidence
knowledge
experience
lesson
skill
doctrine
```

## Process

1. Capture observation with source and time.
2. Extract claims without upgrading truth status.
3. Attach supporting/contradicting evidence.
4. trace shared root sources.
5. identify stale/conflicting evidence.
6. propose knowledge candidates.
7. require independent verification appropriate to consequence.
8. assign validity scope and expiry.
9. track downstream consumers.

## Promotion principle

Persistence increases required evidence.

```text
observation < knowledge < skill < doctrine
```

## Output

Curated objects plus:
- provenance,
- uncertainty,
- conflicts,
- stale risks,
- re-verification requirements.
