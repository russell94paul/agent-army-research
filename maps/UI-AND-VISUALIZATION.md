## UI invariant

The visual world must remain an **observability instrument**.

```text
movement      = real transition
pulse         = event
route flow    = dependency/handoff/supply
formation     = team topology
field         = derived organizational signal
lock          = verification
```

If the UI cannot explain what an animation means technically, remove the animation.
