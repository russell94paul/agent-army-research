# Program Manifest

## Core hypotheses

H1. Entire artificial organizations can become first-class programmable objects.

H2. Mission intent plus bounded authority can outperform rigid central orchestration on changing tasks.

H3. Shared environmental state can reduce unnecessary agent communication.

H4. Organizational knowledge must be typed and provenance-aware rather than stored as undifferentiated memory.

H5. Skills, capabilities and doctrine should be versioned and evaluated like software artifacts.

H6. Dynamic organizational structure can improve utilization, latency and robustness.

H7. Organizational observability must exist before strong structural autonomy.

H8. Historical replay and simulation can allow safer optimization of team topology and policy.

H9. Organizational concepts from mission command, operations research, control theory and artificial life can produce useful new primitives.

H10. A spatial living-world UI can compress complex organizational state more effectively than conventional dashboards if every visual encoding maps to real state.

## Non-goals

- anthropomorphism for its own sake,
- military roleplay,
- replacing evidence with agent consensus,
- autonomous production evolution without controls,
- animation unrelated to real system state,
- claiming novelty without a prior-art review.

## Long-term success criterion

A human can inspect Agent Army and answer:

```text
What is happening?
Why?
What is the organization trying to achieve?
What does it know?
How does it know that?
What is uncertain?
Which capabilities are ready?
Where are resources constrained?
Why did this team form?
Why did this agent act?
What evidence supports the result?
What did the organization learn?
How could it organize itself better next time?
```
