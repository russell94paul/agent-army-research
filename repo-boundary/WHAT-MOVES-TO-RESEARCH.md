# What Moves to Agent Army Research

When separating an existing `docs/agent-army` area from Agent Factory, move material that is primarily:

- research prompts,
- research answers,
- speculative vision,
- external literature synthesis,
- future architecture,
- ontology exploration,
- alternate UI concepts,
- experiments not tied to current code,
- long-term evolution/federation concepts,
- whitepaper/category work,
- theoretical organizational laws,
- unapproved governance proposals.

Examples:

```text
R20–R45 prompts and answers
Artificial Organization Engineering foundations
Mission Command research
stigmergy / morphogenesis
Evolution Chamber research
future Org-IR/compiler research
federation protocol exploration
UI concept research
```

## Do not move blindly

If a document under `docs/agent-army` describes **actual current runtime behavior**, split it:

- current verified facts stay in Agent Factory,
- research/future sections move here.

Preserve Git history where practical.
