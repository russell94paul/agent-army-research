# R31 — Frontier Organizational Primitives

## Objective

Search beyond conventional agent frameworks for mechanisms that could become genuinely useful first-class primitives in Agent Army.

The goal is **not** to collect exotic metaphors. The goal is to identify computational mechanisms that improve:

- verified mission success,
- coordination efficiency,
- adaptation,
- resilience,
- knowledge quality,
- resource utilization,
- observability,
- or human control.

Act as a skeptical interdisciplinary researcher spanning multi-agent systems, distributed systems, artificial life, control theory, organizational science, economics, swarm intelligence, programming languages and human-computer interaction.

## Current candidate frontier ideas

Investigate, attack and extend concepts such as:

```text
organizational fields
digital pheromones
morphogenetic teams
organizational autopoiesis
collective cognition
organizational immune systems
organizational metabolism
capability readiness
temporal echelons
staff functions
organizational genomes
evolution chambers
counterfactual organization simulation
epistemic coverage / fog of war
knowledge and skill economies
```

Do not assume any of these deserve implementation.

## Search method

For every candidate primitive:

1. Find the strongest historical prior art.
2. Find modern LLM-agent analogues.
3. Identify the underlying mechanism independent of metaphor.
4. Explain what state must exist at runtime.
5. Identify the local rule or algorithm.
6. Identify the global behavior expected to emerge.
7. Identify computational and coordination cost.
8. Identify failure modes.
9. Define a baseline.
10. Propose a falsifiable experiment.

> What mechanisms are standard or powerful in adjacent fields but almost absent from today's LLM agent frameworks?

## Primitive quality test

A proposed primitive is valuable only if we can describe:

```text
NAME
PROBLEM
STATE
LOCAL RULE
GLOBAL EFFECT
OWNER
EVENTS
OBSERVABILITY
PERFORMANCE COST
FAILURE MODE
EXPERIMENT
USER VALUE
```

If it cannot be reduced to this level, classify it as metaphorical only.

## Combination effects

Study whether primitives interact.

Examples:

```text
stigmergy + capability readiness
intent + morphogenesis
running estimates + temporal echelons
knowledge provenance + doctrine
simulation + organizational genome
```

Identify positive synergies and dangerous feedback loops.

## Required deliverables

Produce:

1. top 20 frontier primitives ranked by expected value;
2. novelty/prior-art map;
3. mechanism specifications for the top 10;
4. top 10 concepts Agent Army should explicitly avoid;
5. experiment backlog;
6. dependency map;
7. minimum runtime substrate required to test them;
8. UI implications;
9. performance risks;
10. recommended sequence:

```text
BUILD NOW
PROTOTYPE
SIMULATE
RESEARCH FURTHER
REJECT
```

Finish by answering:

> Which three organizational primitives, if validated, would most differentiate Agent Army from ordinary multi-agent orchestration while delivering measurable user value?
