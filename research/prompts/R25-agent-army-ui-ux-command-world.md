# R25 — Agent Army UI/UX: Command World and Artificial Organization IDE

## Objective

Design the primary interface for Agent Army.

It should feel like:

- a premium command center,
- a real-time strategy operations map,
- a digital twin,
- an IDE,
- a distributed-systems debugger,
- and a high-end observability tool.

Use an original visual language.

Do not copy protected game assets, interfaces, logos, typography or characters.

## Main idea

Agents inhabit the environment they modify.

Mapping:

```text
Mission       → Operation
Agent         → Unit
Team          → Squad / Cell
Repository    → Base / District
Service       → Facility
Database      → Infrastructure
API           → Gateway
Artifact      → Object / Site
Tool          → Equipment
Evidence      → Intelligence
Dependency    → Route
Blocker       → Roadblock
Queue         → Traffic
```

## Required surfaces

Design:

- HQ,
- Command World,
- Mission View,
- Squad View,
- Agent Inspector,
- Artifact Inspector,
- Knowledge Inspector,
- Capability Map,
- Evidence Graph,
- Timeline/Replay,
- Organizational Debugger,
- Profiler,
- Evolution Chamber,
- Organization Editor.

## Lenses

```text
Default
Risk
Uncertainty
Knowledge
Attention
Contention
Verification
Cost
Traffic
Readiness
Logistics

Capability
```

## Avoid

- random wandering avatars,
- meaningless particles,
- cheap camouflage,
- unreadable tiny labels,
- constantly rearranging graphs,
- military terms hiding technical meaning,
- decorative animation without semantic state.

## Required output

Produce:

- information architecture,
- 3 visual directions,
- command world layout,
- interaction model,
- semantic zoom,
- motion grammar,
- component architecture,
- data requirements,
- accessibility,
- performance budgets,
- MVP implementation handoff.

End with:

> How do we make the artificial organization feel alive while making it easier to understand and operate?
